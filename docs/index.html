Pick several tags. Get one search.

Sites let you click one tag at a time. This Chrome extension turns the tags already on the page into checkboxes, then opens the one search that finds only the items matching all of them.

Get the extension

Free · no account · nothing is stored or sent anywhere

How it works

  1. Open a supported page — the toolbar icon lights up.
  2. Click the icon. Every tag on the page gets a checkbox.
  3. Tick two or more. They can come from different items on the same page.
  4. Click Find matches. Results open in a new tab; your page stays put.

A true intersection, not a word search

This is the part we refuse to fake. For every supported site we measured real result counts to confirm the combined search returns only items carrying all the selected tags.

On IMDb, Period Drama has 5,162 titles and Prison Drama has 309. Together they return 31. That's an intersection.

Sites that have clickable tags but no true combined search were left out on purpose, rather than shipped with a word-soup search that quietly returns the wrong thing.

Privacy, plainly

  • No accounts, no analytics, no telemetry, no server of any kind.
  • Nothing is stored — not your selections, not your history. No cookies, no local storage.
  • Nothing about the pages you visit is sent anywhere or kept — when you activate it, the current page is read locally to see if the site is supported, and that stays in your browser.
  • It only runs on a page after you click its icon.
  • The only network request it causes is the results tab you asked for.
